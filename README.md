Gnomeboard. A small (76x95 mm) split ergonomic keyboard. 

Features:
- 3x5+1 keys on each side, 32 keys total
- 15mm key spacing
- Choc v1 switch compatibility, no hotswap
- Reversible PCB
- Diodeless, one pin per key (Cradio pinout)
- Nice!Nano v2 footprint for the MCU
- Aggressive pinky stagger

I've designed this keyboard for people with small hands, such as myself. Custom keycaps will likely be needed, but Pseudoku's Philidelphia Minimalist and the MBK Pocket MNT keycaps are small enough to work. This keyboard is based on the Sweep / Cradio / Urchin style keyboards.
