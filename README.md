Gnomeboard. A small (76x95 mm) split ergonomic keyboard. 

Features:
- 3x5+1 keys on each side, 32 keys total
- 15mm key spacing
- Choc v1 switch compatibility, no hotswap
- Reversible PCB
- Diodeless, one pin per key (Cradio pinout)
- Nice!Nano v2 footprint for the MCU
- Aggressive pinky stagger

I've designed this keyboard for people with small hands, such as myself. Custom keycaps will likely be needed, but Pseudoku's Philidelphia Minimalist and the MBK Pocket MNT keycaps are small enough to work. This keyboard is based on the Sweep / Cradio / Urchin style keyboards.

There are .zip files of the Gerbers for the switchplate, the PCB, and a "bottom plate" which is just the normal PCB footprint with a cutout for the JST connector to be mounted under the normal PCB, and all other footprints removed. The "wireless" version has a JST connector for power, and the non-wireless version has a TRRS connector for connecting the split halves. I don't plan on ever building that version. If you do build this board in either fashion, I'd love to hear about it.
